# dsh-claude-brand

把 DeepSeek Harness Web GUI 换成 **Claude 的样子**——星芒标记、文字字标、浏览器标题与图标。

它只改**品牌层**，不动配色，也不动布局：配色是皮肤的事（见 `../claude/`），这个插件一个颜色都不写死，全部跟着当前主题走。

---

## 它是什么

插件做六件事：

1. **侧栏品牌标记**：在 `sidebar.brand.mark` 上以优先级 **-10** 注册，遮住官方占位的鲸鱼 logo，换成内联 SVG 的 Anthropic/Claude 放射状**星芒**（`currentColor`，随主题变色）。
2. **侧栏字标**：在 `sidebar.brand.name` 上把官方的字形轮廓换成真文字 "Claude"。
3. **首屏标记**：同一个星芒，注册到 `conversation.hero.brand.mark`，尺寸略大、显式取品牌强调色。
4. **问候语与标题**：把首屏标题（"探索未至之境" / "Into the Unknown"）换成**24 句轮换问候语**，并改写浏览器标签标题里的产品名。
5. **标签页图标**：页面本身没有任何 `<link rel="icon">`，浏览器会退回请求 `/favicon.svg`——那是 DSH 安装目录里的鲸鱼，升级会被覆盖。插件改为**自己声明**星芒，不去改不属于自己的文件。
6. **身份编辑**：设置 → **Claude-X** 里可以改名字、副标题、头像；侧栏底部（设置上方）另有一行头像 + 名字，点开就是就地编辑弹层。弹层里带一个开关，不想在侧栏放这行可以直接关掉。

它**不依赖任何皮肤**，单独装上就能用——只是配色会跟随你当前用的主题。

### 关于优先级

插槽是**数字越小越优先**，所以 `-10` 压过官方品牌插件的 `0`。同优先级抢同一个独占插槽会直接报错，这也是必须写 `-10` 的原因。

### 身份数据存在哪

名字、副标题、头像存在**这台浏览器**里（localStorage 的 `dsh-claude-brand.prefs`），不写进仓库、不上传。头像是以 data URL 存的——本地没有上传接口，浏览器下次打开得能直接画出来。

> **一处有意的共用**：名字/副标题/头像的编辑界面在**皮肤插件的 Claude-X 设置页**上，这里没另开一页——这些字段本来就是那套皮肤外观的一部分，单独占一个设置项太繁琐。两个插件读同一份记录，改完会互相通知，所以侧栏弹层里改了设置页立刻跟着变。代价是共用同一个存储键：卸载皮肤插件会一并带走那个编辑页（侧栏弹层还在）。这是刻意的取舍。

## 安装

```bash
dsh plugin --profile web add link:/绝对路径/dsh-claude-theme/brand-plugin
```

装完**重启一次 DSH**（新增插件需要重启才会进入启动图谱），然后刷新页面。

验证生效：侧栏鲸鱼 logo 应变成星芒、品牌文字应变成 "Claude"、标签标题里不应再有 "DeepSeek Harness"、标签图标应从鲸鱼变成星芒。**没重启的话这四处都不会变。**

卸载：

```bash
dsh plugin --profile web remove dsh-claude-brand
```

## 它挂在哪

| 位置 | 放什么 |
| --- | --- |
| `sidebar.brand.mark` | 星芒标记，优先级 -10 |
| `sidebar.brand.name` | "Claude" 字标 |
| `conversation.hero.brand.mark` | 首屏星芒 |
| `sidebar.footer.action` | 侧栏底部头像行 + 就地编辑弹层 |

它**没有自己的设置页**——名字/副标题/头像的编辑界面在皮肤插件的 Claude-X
页上（那是皮肤外观的一部分）。只装本插件时用侧栏底部的弹层。

host 半边（`lib/index.js`）**是空的**——这个插件所有的事都发生在浏览器里，没有宿主状态、没有要来回传的数据。文件存在只是为了让插件能被正常加载。

### 关于文本改写

问候语和标题是直接改页面上的文字的（`installBrandText` / `installFavicon`），没有走官方的插槽——那几行字是写死的，插槽体系里没有它们的位置。代价是：官方哪天改了文案，替换就会落空（此时星芒和字标不受影响）。

---

## 已知限制

- **只改品牌层**。配色、字体、圆角都不在这里——那是皮肤的事。想换配色请装皮肤。
- **文本替换依赖官方文案原文**。官方改了标题文字，问候语替换会失效。
- **头像存在 localStorage**。图片以 data URL 存储，浏览器存储配额有限；太大的图会被浏览器拒绝（此时控制台会有告警，界面保持原样）。
- **身份编辑页在皮肤插件那侧**。只装这个插件的话，改名字要用侧栏底部的弹层；设置页那一栏来自皮肤插件。关掉底部那行的开关两边都有（弹层里和 Claude-X 页），关掉后数据不丢。
